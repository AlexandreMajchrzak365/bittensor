Participer

Du plus simple au plus exigeant : staker, miner, valider, créer son subnet. Moi, je fais tout avec btcli, l'outil en ligne de commande officiel, dans le Terminal du Mac.

Installer btcli sur un Mac

Dans le Terminal, on crée un environnement Python à part, puis on y installe l'outil :

python3 -m venv ~/bittensor
source ~/bittensor/bin/activate
pip install bittensor-cli
btcli --help

btcli évolue vite et certaines commandes changent de nom d'une version à l'autre. En cas de doute, btcli --help et la documentation officielle font foi. Les sorties ci-dessous sont simplifiées.

Choisissez votre rôle

Staker : le plus accessible

Facile Aucune machine à faire tourner : vous confiez vos TAO à un validateur et touchez une part de ses récompenses, moins sa commission (18 % par défaut).

  1. Obtenir des TAO sur une plateforme d'échange, puis les retirer vers votre propre coldkey.
  2. Commencer par root (subnet 0) : vos TAO restent des TAO.
  3. Choisir un validateur sérieux : identité publique, commission raisonnable, ancienneté.
  4. Plus tard, et en connaissance de cause, staker sur un subnet dont vous comprenez le produit.

Sans terminal, des portefeuilles en extension de navigateur permettent aussi de staker.

zsh 
# 1. Créer un portefeuille (coldkey + hotkey)
btcli wallet create -w moi
Écrivez votre phrase secrète sur papier. Ne la photographiez pas.
# 2. Vérifier son solde
btcli wallet balance -w moi
Free balance : 12.0000 τ
# 3. Voir les subnets et leurs prix
btcli subnets list
# 4. Staker sur root (subnet 0), le choix prudent
btcli stake add --netuid 0 -w moi
Choisissez un validateur, puis le montant. Confirmer ? [y/n]
# 5. Suivre ses positions
btcli stake list -w moi

Mineur : fournir le travail

Exigeant Chaque subnet a sa tâche, ses règles et son matériel conseillé, décrits dans son dépôt GitHub.

  1. Choisir un subnet et lire toute sa documentation.
  2. Payer l'inscription : ce prix varie avec la demande et il est brûlé, jamais rendu.
  3. Lancer le code du mineur sur une machine Linux ou Mac (Windows n'est pas pris en charge).
  4. Profiter de la période d'immunité pour s'améliorer : ensuite, le moins bon mineur est remplacé par chaque nouvel inscrit.
zsh 
# 1. Étudier le subnet : prix d'inscription, règles
btcli subnets show --netuid 64
btcli sudo get --netuid 64
# 2. Une hotkey par machine de minage
btcli wallet new-hotkey -w moi -H mineur1
# 3. S'inscrire : le prix est brûlé, pas remboursé
btcli subnets register --netuid 64 -w moi -H mineur1
Inscrit. UID 173. Période d'immunité en cours.
# 4. Lancer le code du mineur, selon le dépôt du subnet
git clone https://github.com/<equipe>/<subnet>.git
python neurons/miner.py --netuid 64 --wallet.name moi --wallet.hotkey mineur1

Validateur : noter les autres

Très exigeant Seuls les participants les plus dotés en stake d'un subnet obtiennent le permis de validateur. En pratique, il faut des dizaines de milliers de TAO, à soi ou confiés par des stakers.

  1. S'inscrire sur le subnet, comme un mineur.
  2. Réunir assez de stake pour entrer dans le classement des validateurs.
  3. Faire tourner le code de validation, qui envoie les notes régulièrement.
  4. Garder la coldkey loin du serveur : seule la hotkey y est nécessaire.
zsh 
# Un validateur doit être parmi les plus dotés en stake
btcli subnets register --netuid 64 -w moi -H valid1
btcli stake add --netuid 64 -w moi -H valid1
# Vérifier si l'on a obtenu le permis de validateur
btcli subnets metagraph --netuid 64
# Le code du validateur envoie ses notes automatiquement
python neurons/validator.py --netuid 64 --wallet.name moi --wallet.hotkey valid1
# Pour attirer des stakers : se présenter et fixer sa commission
btcli wallet set-identity -w moi

Créer un subnet : écrire les règles du jeu

Projet d'entreprise Le créateur invente une tâche utile et une façon fiable de la noter, puis doit convaincre des mineurs, des validateurs et des stakers de le rejoindre.

  1. Tout tester gratuitement sur le réseau de test (--network test) ou sur une chaîne locale.
  2. Payer le prix de création, qui varie selon la demande.
  3. Survivre à la période de protection de quatre mois, puis attirer assez de TAO pour ne pas être désinscrit.
zsh 
# S'entraîner d'abord sur le réseau de test, gratuit
btcli subnets create -w moi --network test
# Sur le vrai réseau, le prix de création est brûlé
btcli subnets burn-cost
btcli subnets create -w moi
# Écrire le mécanisme d'incitation : quoi miner, comment noter
git clone https://github.com/opentensor/bittensor-subnet-template.git

Ou simplement : utiliser ce que le réseau produit

On peut participer sans posséder un seul TAO : en tant que client. Plusieurs subnets vendent leurs services comme n'importe quelle entreprise, par exemple des modèles d'IA ouverts via l'API de Chutes, ou de la location de cartes graphiques sur Lium.

Six règles de sécurité

  1. La phrase secrète s'écrit sur papier. Jamais en photo, jamais dans un fichier, jamais dans un chat.
  2. Aucun « support » ne vous la demandera. Quiconque la demande essaie de vous voler.
  3. La coldkey ne va jamais sur une machine de minage ou de validation.
  4. Tout s'essaie d'abord sur le réseau de test.
  5. On ne mise que ce qu'on accepte de perdre entièrement.
  6. On se méfie de toute offre pressée : l'urgence est l'arme préférée des arnaques.
