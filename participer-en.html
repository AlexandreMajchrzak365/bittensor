Step 5

Take part

From the simplest to the most demanding: staking, mining, validating, creating your own subnet. Personally, I do everything with btcli, the official command-line tool, in the Mac Terminal.

Installing btcli on a Mac

In the Terminal, create a separate Python environment, then install the tool in it:

python3 -m venv ~/bittensor
source ~/bittensor/bin/activate
pip install bittensor-cli
btcli --help

btcli changes fast and some commands get renamed from one version to the next. When in doubt, btcli --help and the official documentation are the reference. The outputs below are simplified.

Choose your role

Staking: the most accessible

Easy No machine to run: you lend your TAO to a validator and get a share of their rewards, minus their take (18% by default).

  1. Get TAO on an exchange, then withdraw them to your own coldkey.
  2. Start with root (subnet 0): your TAO stay TAO.
  3. Choose a serious validator: public identity, reasonable take, track record.
  4. Later, knowingly, stake on a subnet whose product you understand.

Without a terminal, browser-extension wallets also let you stake.

zsh 
# 1. Create a wallet (coldkey + hotkey)
btcli wallet create -w me
Write your secret phrase on paper. Do not photograph it.
# 2. Check your balance
btcli wallet balance -w me
Free balance: 12.0000 τ
# 3. List the subnets and their prices
btcli subnets list
# 4. Stake on root (subnet 0), the careful choice
btcli stake add --netuid 0 -w me
Choose a validator, then the amount. Confirm? [y/n]
# 5. Follow your positions
btcli stake list -w me

Mining: providing the work

Demanding Each subnet has its task, its rules and its recommended hardware, described in its GitHub repository.

  1. Choose a subnet and read all its documentation.
  2. Pay the registration: the price varies with demand and is burned, never returned.
  3. Run the miner code on a Linux or Mac machine (Windows is not supported).
  4. Use the immunity period to improve: after that, the weakest miner is replaced by each newcomer.
zsh 
# 1. Study the subnet: registration price, rules
btcli subnets show --netuid 64
btcli sudo get --netuid 64
# 2. One hotkey per mining machine
btcli wallet new-hotkey -w me -H miner1
# 3. Register: the price is burned, not refunded
btcli subnets register --netuid 64 -w me -H miner1
Registered. UID 173. Immunity period running.
# 4. Run the miner code, following the subnet's repository
git clone https://github.com/<team>/<subnet>.git
python neurons/miner.py --netuid 64 --wallet.name me --wallet.hotkey miner1

Validating: scoring the others

Very demanding Only the participants with the most stake in a subnet get the validator permit. In practice, you need tens of thousands of TAO, your own or lent by stakers.

  1. Register on the subnet, like a miner.
  2. Gather enough stake to enter the validator ranking.
  3. Run the validation code, which sends scores regularly.
  4. Keep the coldkey away from the server: only the hotkey is needed there.
zsh 
# A validator must be among those with the most stake
btcli subnets register --netuid 64 -w me -H valid1
btcli stake add --netuid 64 -w me -H valid1
# Check whether you got the validator permit
btcli subnets metagraph --netuid 64
# The validator code sends its scores automatically
python neurons/validator.py --netuid 64 --wallet.name me --wallet.hotkey valid1
# To attract stakers: introduce yourself and set your take
btcli wallet set-identity -w me

Creating a subnet: writing the rules of the game

A business project The creator invents a useful task and a reliable way to score it, then has to convince miners, validators and stakers to join.

  1. Test everything for free on the test network (--network test) or on a local chain.
  2. Pay the creation price, which varies with demand.
  3. Survive the four-month protection period, then attract enough TAO not to be deregistered.
zsh 
# Practise first on the test network, for free
btcli subnets create -w me --network test
# On the real network, the creation price is burned
btcli subnets burn-cost
btcli subnets create -w me
# Write the incentive mechanism: what to mine, how to score
git clone https://github.com/opentensor/bittensor-subnet-template.git

Or simply: use what the network produces

You can take part without owning a single TAO: as a customer. Several subnets sell their services like any company, for example open AI models through the Chutes API, or graphics card rental on Lium.

Six safety rules

  1. The secret phrase is written on paper. Never in a photo, never in a file, never in a chat.
  2. No “support” will ever ask for it. Anyone who asks is trying to rob you.
  3. The coldkey never goes on a mining or validating machine.
  4. Try everything on the test network first.
  5. Only stake what you are ready to lose entirely.
  6. Distrust any rushed offer: urgency is the scammers' favourite weapon.
